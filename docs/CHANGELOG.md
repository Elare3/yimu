# Changelog

## v0.1.0 (2026-03-21)

### Initial Implementation
- Project initialization with Next.js 14 + TypeScript + Tailwind CSS
- MongoDB + Prisma ORM setup with full schema (User, Client, Project, Quote, Transaction, PaymentNode)
- NextAuth.js authentication with phone + verification code
- Dashboard with summary cards, income/expense trend chart, recent projects, upcoming payments
- Client management: CRUD, search, tag filtering, card display
- Project management: Kanban board with drag-and-drop, list view, project detail page, status machine
- Quote management: manual creation, AI-powered generation, quote detail/edit
- Finance: manual bookkeeping, AI transaction parsing, monthly summary
- Payment tracking: payment nodes, AI reminder generation, mark-as-paid
- Settings page with user info and logout
- Full API routes for all business modules
- Responsive design: desktop sidebar + mobile bottom navigation
- Brand design system: cream latte color palette, serif/sans-serif font system
